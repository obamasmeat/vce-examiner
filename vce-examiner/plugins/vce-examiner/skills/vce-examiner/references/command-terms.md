# VCE command terms and what assessors expect

The command term sets the ceiling on marks. Check it first, every time. An answer that does a lower-order task than the term demands is capped, however accurate it is.

| Term | What it demands | Common way students lose marks |
|------|-----------------|-------------------------------|
| **Identify / State / Name** | Recognise and give a fact or feature. Brief. | Writing a paragraph (wastes time, risks a contradiction). Giving two answers when one is asked; the first is usually marked. |
| **Outline** | Brief summary of main features, no detail. | Going too deep and running out of time elsewhere. |
| **Describe** | Give the characteristics or features of something, in detail. *What* it is or what happens. | Just naming, no detail. Explaining "why" is fine but not required. |
| **Explain** | Give reasons or causes: *how* and *why*. Show the link (because / therefore / which leads to). | Describing what happens with no "because". Missing the causal link is the most common lost mark in VCE. |
| **Analyse** | Break into parts, examine each, and show relationships, patterns or implications. | Listing parts without connecting them. No "so what". |
| **Compare** | Show similarities **and** differences, point by point, using comparative language (whereas, similarly, in contrast). | Two separate descriptions with no comparative link. Only differences given. |
| **Contrast** | Differences only, explicitly linked. | Same as compare: two separate blocks. |
| **Distinguish between** | Make clear the difference between two things. | Defining each without stating the difference. |
| **Discuss** | Consider different points of view or sides, with evidence, usually leading somewhere. | One-sided. No counter-view. |
| **Evaluate** | Weigh strengths **and** weaknesses (or for/against), then make a **judgement** with justification. | No final judgement. Strengths only. Judgement with no reasoning. |
| **Assess** | Judge the value, significance or extent of something, with reasons. | Describing without measuring "to what extent". |
| **Justify** | Give reasons and evidence supporting a decision or conclusion. | Restating the conclusion as its own justification. |
| **Apply** | Use knowledge in the given scenario. | Generic theory with no reference to the stimulus. |
| **Propose / Suggest / Recommend** | Put forward a reasoned option, usually with justification. | No reason. Unrealistic option for the scenario. |
| **Calculate / Determine / Find** | Get a value. Show working. Units and appropriate significant figures where relevant. | No working (loses method marks if the answer is wrong). Missing units. Wrong sig figs. |
| **Show that** | Prove a given result. Every step must be shown. | Skipping steps; working backwards from the answer. |
| **Hence** | Must use the previous result. | Solving from scratch (often gets 0). |
| **Hence or otherwise** | Previous result recommended, any valid method accepted. | — |
| **Sketch** | Shape and key features (intercepts, asymptotes, turning points, endpoints), labelled. Not to scale. | Missing labels, coordinates, or endpoint types (open/closed). |
| **Draw / Plot** | Accurate, to scale where relevant. | Freehand lines, wrong scale, missing axis labels/units. |
| **Interpret** | Draw meaning from data or text and explain it. | Restating numbers without saying what they mean. |
| **To what extent** | A judgement of degree (fully / largely / partially / minimally), argued both ways. | Yes/no answer with no degree. |

## Mark-count heuristics

- 1 mark: one correct, precise point.
- 2 marks: two points, or a point plus its explanation/link.
- 3 marks: typically point + explanation + link to the scenario/data.
- 4+ marks: multiple developed points, often needing both sides (evaluate) and a judgement. Tell the student how many distinct creditable elements the allocation implies, and count theirs.

These are heuristics. If the student provides a marking guide, use it instead.
