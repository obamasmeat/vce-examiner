# VCE English as an Additional Language (EAL) (Study Design from 2024)

Sources: VCAA exam specifications, 2025 and 2024 external assessment reports. My own summary.
**Read `english.md` as well.** EAL shares the English exam structure and criteria. This file lists only the EAL-specific notes.

## Exam format
Same three sections as English, each worth 20 marks (60 total): **A** analytical response to one text from the shared English/EAL text list, **B** creating a text (fixed title, stimulus, Framework of Ideas), **C** analysis of argument, language and visuals. Marked holistically against the same style of criteria. Printed English and/or bilingual dictionaries are allowed.

## EAL-specific emphasis from the reports
**Section A**
- Turn the topic into a question and address **all** its key ideas.
- The contention and every argument must respond to that question.
- Build an interpretation from **key moments** in the text. Consider multiple valid interpretations.
- Explain how the text's **construction** (structure, language, form) conveys meaning.

**Section B**
- The mandated title should feel *made for* the piece. Use an idea from the title to set your purpose (e.g. "to reflect on how I had to change direction…").
- Use the stimulus to add an idea, describe a moment or create cohesion.
- **Scope to the time limit**: one focused moment or idea, developed in detail, beats several rushed events.
- Low scorers drew on ideas outside the Framework they studied.
- Expression is judged for control, but varied control doesn't stop a strong text scoring well if its purpose and ideas are clear.

**Section C**
- Show the context (annotate the background information).
- Analyse how argument, language and visuals **complement each other** to position the intended audience. Go beyond listing persuasive devices.
- Track **how the argument develops** through the text (a flow chart of arguments helps when planning).
- Select key examples and explain the intended effect of each.

## Marking notes for this skill
- Apply the English expected qualities. For expression, prioritise **clarity of meaning** over perfect grammar, but still flag errors that blur meaning, and give the corrected sentence.
- Give vocabulary upgrades as part of the teaching: precise analytical verbs (*positions, invites, reinforces, undermines*) and topic-specific vocabulary.
